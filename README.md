# youtube-backend
Developed a robust YouTube backend system using Node.js and Express, featuring video and photo uploads to Cloudinary. Implemented user authentication and authorization, allowing users to comment, like, and view videos. Ensured that only the video owner could delete comments and edit video titles and descriptions. Integrated view count tracking for each video. Utilized MongoDB for data storage and incorporated middleware for request validation and error handling. Leveraged various libraries including bcrypt for password hashing, JSON Web Token for authentication, and multer for handling file uploads. This project demonstrates proficiency in backend development, handling multimedia content, user management, and integration of third-party services.
